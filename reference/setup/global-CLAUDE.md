Richmade keeps a knowledge base in `~/Documents/AI Agency/claude-journal` for a future overnight agent. When any of the following happens in a session, first do the request the normal way. Then open the `session-journal` skill and follow its "Capturing moments: do it, then log it" section to record it:

- you commit and push work in a project repo (not the claude-journal repo itself)
- Jake asks you to remember a preference ("remember that I prefer...")
- you write an SOP or process document
- you edit a repo's CLAUDE.md
- you produce a weekly wrap

Keep the logging light: one line in chat saying what was logged. No full journal or rules question unless Jake asks.
